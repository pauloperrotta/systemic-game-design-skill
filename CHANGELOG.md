# Changelog

## 0.1.0 - 2026-10-17

- First version of the skill: `SKILL.md` with the three flows (design, analyze, balance), the vocabulary, the failure table and output formats.
- Six reference files built from the systems-design method (loops, interactivity, parts, balance, vision and analysis, prototyping and playtest).
- Evaluation set (3 prompts, 23 assertions) and a first run: 23/23 with the skill, 21/23 without.
- Finding: the skill is rarely auto-triggered without being named. A rewritten description did not help and was not adopted.

- English translation of the skill is now the main version in `skills/`; the Spanish original moved to `i18n/es/`.
